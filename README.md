# 🏍️ Rapido Analytics Dashboard

<p align="center">
  <b>An interactive Power BI dashboard analyzing Rapido ride operations, revenue, driver performance, and business insights.</b>
</p>

---

## 📌 Project Overview

The **Rapido Analytics Dashboard** is a professional Power BI project designed to analyze ride-booking operations across Bike, Cab, and Auto services. The dashboard transforms raw transportation data into meaningful business insights through interactive visualizations, KPI tracking, and dynamic filtering.

---

## 📊 Dashboard Pages

### 🏠 Executive Dashboard
Provides a complete overview of Rapido's business performance.

**KPIs**
- Total Rides
- Total Revenue
- Total Drivers
- Total Customers
- Average Fare
- Cancellation Rate

**Visuals**
- Revenue Trend
- Ride Distribution
- State-wise Revenue
- Ride Status
- Payment Method Analysis

---

### 🏍️ Bike Analytics

Analyze Bike ride performance across different regions.

**Insights**
- Total Bike Rides

- Monthly Revenue Trend

- State-wise Ride Analysis
- Peak Booking Hours
- Payment Method Distribution
- Performance Matrix
